# 流年小账本 · 后端接口文档

> 家庭共享记账微信小程序后端（Spring Boot 3.3 + MyBatis-Plus）。
> 更新日期：2026-10-19（邀请拆分为 invitation + join_request、成员/流水状态调整）。本文件覆盖全部 REST 接口，字段以代码实现为准。

## 通用约定

- **Base URL**：`http://<host>:<port>/api`（开发环境端口 `8445`，context-path `/api`）。
- **请求/响应格式**：均为 JSON，`Content-Type: application/json; charset=UTF-8`。
- **鉴权**：除下方标注「接口层不校验 token（匿名可调用）」的接口外，其余接口均需在请求头携带：

  | 请求头        | 类型   | 必填 | 说明                              |
  | ------------- | ------ | ---- | --------------------------------- |
  | Authorization | String | 是   | `Bearer ` + 登录返回的 `token`    |

  缺省或非法 token 返回 `{"code":401,"msg":"未登录/鉴权失败/登录已失效"}`。
- **统一响应结构**：`{ "code": int, "msg": string, "data": object|array|null }`。`code=0` 表示成功；非 0 为业务错误，错误信息在 `msg`。
- **金额单位**：所有 `amount` 字段均为整数「分」（如 `3500` 表示 ¥35.00）。
- **日期格式**：入参/出参日期为 `yyyy-MM-dd`；提醒时间为 `HH:mm`（24 小时）。格式错误或查询参数类型不匹配统一返回 `400`（不会 500）。
- **ID 类型**：`familyId` / `memberId` / `categoryId` / `id`（账目、邀请等）均为自增 `BIGINT`，以数字（JSON number）传递，字符串分类字面量（如 `g_exp_food`）已废弃。

### 错误码

| code | 含义                                   |
| ---- | -------------------------------------- |
| 400  | 参数错误 / 资源不存在（如分类、记录）  |
| 401  | 未登录 / token 无效或已失效            |
| 403  | 越权（非家庭成员 / 仅创建者可操作）    |
| 409  | 冲突（重复操作 / 人数上限）            |
| 410  | 已失效（邀请过期 / 已撤销 / 不存在）  |
| 500  | 服务器内部错误                         |

### 1. 用户登录（微信 code 换 token）

**接口地址**: `/login`

**请求方式**: `POST`

**是否鉴权**: 否（接口层不校验 token，匿名可调用）

**请求参数**:

| 参数名   | 类型   | 必填 | 说明                         |
| -------- | ------ | ---- | ---------------------------- |
| code     | String | 是   | 微信登录 code（wx.login 获取）|
| unionid  | String | 否   | 微信 unionid（授权后回传）   |
| nickname | String | 否   | 用户昵称（首次自动建用户）   |
| avatar   | String | 否   | 头像 URL                     |

**请求示例**:

```json
{
  "code": "081abc...",
  "nickname": "小明",
  "avatar": "https://x/a.png"
}
```

**响应示例**:

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "openid": "oABC123def",
    "isMember": true,
    "familyId": 1,
    "privacyAgreed": true
  }
}
```

**响应字段说明**:

| 字段          | 类型           | 说明                                          |
| ------------- | -------------- | --------------------------------------------- |
| token         | String         | JWT，有效期见服务端配置；需存入本地后续携带   |
| openid        | String         | 用户唯一标识                                  |
| isMember      | Boolean        | 是否已加入某家庭（true 可直进账本）           |
| familyId      | Long/空字符串  | 默认家庭 ID（最早加入的家庭）；未加入家庭时为 `""` |
| privacyAgreed | Boolean        | 是否已同意隐私协议，前端可直接据此决定是否弹窗 |

**业务说明**:

- 用 `code` 调微信 `code2Session` 换取 `openid`；首次登录自动创建 `user` 记录。
- 请求体携带 `nickname`/`avatar` 时，作为「最新授权值」刷新 `user` 表（昵称/头像的唯一权威来源）。
- 登录成功后在 Redis 写入 `auth:jti:<jti>` 实现会话（支持主动失效）；后续请求依赖该 token。
- `WX_MOCK=true` 时 `code` 可为任意字符串，跳过真实微信校验（仅开发环境）。

**错误码**:

| code | 说明                       |
| ---- | -------------------------- |
| 400  | 参数错误：code 不能为空    |
| 401  | 获取 openid 失败           |

### 3. 查询邀请（分享链接落地页）

**接口地址**: `/invitation/{token}`

**请求方式**: `GET`

**是否鉴权**: 公开预览（接口层不强制校验 token，匿名可调用）；**但建议在请求头携带 `Authorization: Bearer <jwt>`**——只有携带合法 JWT 时，后端才会基于当前用户 openid 计算三态字段（`applied` / `applicationStatus`）；不携带则这两个字段退化为 `applied=false` / `applicationStatus="none"`。

**路径参数**:

| 参数名 | 类型   | 必填 | 说明         |
| ------ | ------ | ---- | ------------ |
| token  | String | 是   | 邀请令牌     |

**响应示例**:

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "familyName": "流年小账",
    "inviterNickname": "创建者",
    "inviterAvatar": "https://x/a.png",
    "status": "active",
    "familyId": 33,
    "expireAt": "2026-10-20T14:38:00",
    "applied": true,
    "applicationStatus": "pending"
  }
}
```

**响应字段说明**:

| 字段              | 类型    | 说明                                                                 |
| ----------------- | ------- | -------------------------------------------------------------------- |
| familyName        | String  | 邀请所属家庭名称                                                     |
| inviterNickname   | String  | 邀请人昵称                                                           |
| inviterAvatar     | String  | 邀请人头像                                                           |
| status            | String  | 邀请状态，有效时恒为 `active`（失效直接返回 410）                    |
| familyId          | Long    | 该邀请指向的目标家庭 ID（单值）                                      |
| expireAt          | String  | 邀请过期时间（ISO，ISO-8601 本地时间）                               |
| applied           | Boolean | 当前用户是否已对该家庭提交过申请                                     |
| applicationStatus | String  | 申请状态，**必返回**，取值：`none`(未申请) / `pending` / `approved` / `rejected` |

**前端三态分流建议**:

```js
const s = data.applicationStatus;
if (s === 'approved')                  { /* 已进家庭 → 写会话跳首页 */ }
else if (data.applied && s === 'pending') { /* 已申请待审 → 等待审批页 */ }
else                                   { /* 'none' 或 'rejected' → 邀请确认页 */ }
```

> 说明：`applied` / `applicationStatus` 依据 `(familyId, 当前用户 openid)` 判定——已是成员 → `approved`；否则查 `join_request` 最近一条记录（`pending`/`rejected` 参与三态，`expired`/`canceled` 视为未申请）。`applicationStatus` 恒为非空字符串（`none` 表示未申请），不会缺省。

**错误码**:

| code | 说明                                 |
| ---- | ------------------------------------ |
| 410  | 邀请已失效（不存在/已过期/已撤销） |

### 4. 申请加入家庭

**接口地址**: `/invitation/{token}/apply`

**请求方式**: `POST`

**是否鉴权**: 需要 `Authorization`（申请人必须已登录，后端以 JWT 中的 openid 作为申请人）

**路径参数**:

| 参数名 | 类型   | 必填 | 说明     |
| ------ | ------ | ---- | -------- |
| token  | String | 是   | 邀请令牌 |

**请求参数**:

| 参数名  | 类型   | 必填 | 说明           |
| ------- | ------ | ---- | -------------- |
| nickname| String | 否   | 申请人昵称     |
| avatar  | String | 否   | 申请人头像 URL |

**请求示例**:

```json
{ "nickname": "小明", "avatar": "http://x/a.png" }
```

**响应示例**:

```json
{ "code": 0, "msg": "", "data": { "status": "pending" } }
```

**业务说明**:

- 邀请有效（未撤销且未过期）且申请人不在该家庭时，写入一条 `join_request(status=pending)`，并通知创建者。
- **不消耗邀请**：一条邀请可被多人使用（1:N），也不再写 `family_member`（审批通过后才写入）。
- 同一家庭同一人重复提交：直接刷新昵称头像并返回 `pending`（幂等，由唯一键兜底）。
- 申请人昵称优先取请求体，其次 `user.nickname`，最后「新成员」；头像同理。

**错误码**:

| code | 说明                       |
| ---- | -------------------------- |
| 410  | 邀请已失效（不存在/已撤销/已过期） |
| 409  | 你已在该家庭中             |

### 8. 生成邀请（创建者操作）

**接口地址**: `/invitation`

**请求方式**: `POST`

**请求头**: 需要 `Authorization`

**请求参数**:

| 参数名   | 类型   | 必填 | 说明                                          |
| -------- | ------ | ---- | --------------------------------------------- |
| familyId | Long   | 是   | 家庭 ID                                       |
| type     | String | 否   | `share`（默认，普通分享）或 `qr`（带小程序码）|

**请求示例**:

```json
{ "familyId": 1, "type": "qr" }
```

**响应示例**:

```json
{
  "code": 0, "msg": "",
  "data": {
    "token": "551a9fb48cd74203aa205eb81c103ef3",
    "type": "qr",
    "expireAt": "2026-10-20T14:36:00",
    "reused": true,
    "qrImageUrl": "https://.../wxacode.png"
  }
}
```

**响应字段说明**:

| 字段       | 类型    | 说明                                  |
| ---------- | ------- | ------------------------------------- |
| token      | String  | 邀请令牌（用于分享链接 / apply / 小程序码）|
| type       | String  | `share` / `qr`                        |
| expireAt   | String  | 过期时间（ISO，默认 24 小时后）        |
| reused     | Boolean | `true`=复用已有邀请，`false`=本次新建  |
| qrImageUrl | String  | `type=qr` 时返回小程序码 URL，否则为 `""` |

**业务说明**:

- 仅创建者可生成；家庭人数达上限（默认 10）返回 409。
- **优先复用**：同家庭同 `type` 若存在「未撤销 + 未过期 + 剩余有效期 ≥ `invite.renew-threshold-hours`（默认 6 小时）」的邀请，直接返回原 token（`reused=true`）；否则新建一条，有效期 `invite.expire-hours`（默认 24 小时）。
- 邀请令牌为 UUID（无连字符），非数据库 ID；未过期即可使用，取消 `used` 字段。
- **「复制链接」暂未启用**：当前邀请仅通过小程序码（扫码）加入，响应不返回 `urlLink`。若后续需要在微信外复制真实链接，需后端调用微信 `generate_urllink` 且小程序账号具备「获取 URL Link」权限（个人账号受限，返回 `85407`）；届时再启用并在响应中返回 `urlLink`（方法 `WxService.generateUrlLink` 已预留）。

**错误码**:

| code | 说明               |
| ---- | ------------------ |
| 403  | 仅创建者可操作     |
| 409  | 家庭人数已达上限   |

### 11. 同意加入申请（创建者）

**接口地址**: `/family/{familyId}/join-request/{requestId}/approve`

**请求方式**: `POST`

**请求头**: 需要 `Authorization`

**路径参数**:

| 参数名    | 类型 | 必填 | 说明           |
| --------- | ---- | ---- | -------------- |
| familyId  | Long | 是   | 家庭 ID        |
| requestId | Long | 是   | 申请记录 ID    |

**响应示例**:

```json
{ "code": 0, "msg": "", "data": null }
```

**错误码**:

| code | 说明                 |

### 16. 退出家庭

**接口地址**: `/family/{familyId}/quit`

**请求方式**: `POST`

**请求头**: 需要 `Authorization`

**路径参数**: `familyId` (Long, 必填)

**响应示例**:

```json
{ "code": 0, "msg": "", "data": null }
```

**业务说明**（按家庭现状分三种情况）：

1. **家庭仅剩本人**：直接**彻底解散**该家庭，删除家庭及其全部关联数据（账单、邀请/申请、家庭自定义分类、提醒设置、预算、成员绑定），历史数据一并清除（与「解散家庭」同一套逻辑）。
2. **还有其他成员，且本人不是创建者**：**作废**本人该家庭下的全部流水（`transaction.status=0`，保留数据但不参与任何查询/统计）+ 物理删除本人在 `family_member` 中的行。
3. **还有其他成员，且本人是创建者**：与上一条相同（作废流水 + 删除成员行）；同时将剩余成员中 `joinedAt` 最早加入的一位自动设为新创建者（其 `role` 升为 `owner`，家庭 `creatorOpenid` 同步更新）。如仍需指定受让人，可先用「15. 转让创建者身份」再退出。

> 重要语义变更：成员退出/被移除后，其历史账目**不再计入家庭收支与统计**（数据保留可审计）。前端退出二次确认需提示「你本人在该家庭的 N 笔账目将作废」。

> 创建者不再被「须先转让身份」限制，退出时由系统自动完成创建者交接。

**错误码**:

| code | 说明         |
| ---- | ------------ |
| 403  | 非本家庭成员 |

### 37. 上传图片（记账凭证）

**接口地址**: `/upload`

**请求方式**: `POST`（`multipart/form-data`）

**请求头**: 需要 `Authorization`

**请求参数**:

| 参数名   | 类型   | 必填 | 说明                                       |
| -------- | ------ | ---- | ------------------------------------------ |
| file     | File   | 是   | 图片文件，≤5MB，支持 jpg/jpeg/png/webp/heic |
| familyId | Long   | 否   | 传入则校验调用者是该家庭成员                |

**响应示例**（已配置 CDN 基地址 `APP_PUBLIC_BASE_URL=https://images.sean.ltd`）:

```json
{
  "code": 0, "msg": "",
  "data": {
    "key": "2026/10/5f2c9b1e8a7d4c6fb0a3e2d1c4b5a697.jpg",
    "url": "https://images.sean.ltd/2026/10/5f2c9b1e8a7d4c6fb0a3e2d1c4b5a697.jpg",
    "fullUrl": "https://images.sean.ltd/2026/10/5f2c9b1e8a7d4c6fb0a3e2d1c4b5a697.jpg",
    "size": 183420,
    "contentType": "image/jpeg"
  }
}
```

未配置 `APP_PUBLIC_BASE_URL` 时（本地开发），`url` 为本地静态相对路径：

```json
{ "key": "2026/10/a.jpg", "url": "/api/files/2026/10/a.jpg", "fullUrl": "/api/files/2026/10/a.jpg" }
```

**响应字段说明**:

| 字段        | 类型   | 说明                                                                 |
| ----------- | ------ | -------------------------------------------------------------------- |
| key         | String | 存储相对路径 `yyyy/MM/<uuid>.<ext>`，不含域名                        |
| url         | String | 图片访问地址。**配置了 `app.public-base-url` 时是绝对 URL**，否则是本地相对路径。**直接存入 `transaction.images`** |
| fullUrl     | String | 与 `url` 完全相同（保留该字段仅为兼容旧前端）                        |
| size        | Long   | 文件字节数                                                           |
| contentType | String | 客户端声明的 MIME                                                     |

**业务说明**:

- 文件名使用 UUID，按 `yyyy/MM` 分目录落盘到 `app.upload.dir`（容器默认 `/app/data/upload`）。
- **绝对地址拼接规则**：`app.public-base-url` + `/` + `key`。该基地址语义是「上传根目录的对外访问地址」（CDN 或域名），**末尾不要带 `/`**；配置后不再拼接 `/api/files` 前缀。
- `/api/files/**` 静态映射始终保留，用于本地开发直连与 CDN 故障降级（其 URL 结构与 `key` 一致）。
- 前端拿到 `url` 后**直接使用，不要再拼接域名或 BASE**，否则会得到 `https://cdn...https://cdn...` 这类错误地址。
- 扩展名白名单 + 文件头（magic bytes）双校验，拒绝改扩展名的非图片文件。
- **权限面说明**：图片静态资源不校验 token（`<image src>` 无法携带 Authorization 头），任何拿到 URL 的人可读；安全性依赖不可猜测的 UUID 文件名。
- 图片文件不会随账单删除而清理（后续可加清理任务）。

**小程序调用示例**:

```js
// 1) 先压缩：3MB 照片压到 200-400KB，显著降低上传耗时与流量
wx.compressImage({
  src: tempFilePath,
  quality: 60,
  compressedWidth: 1280,
  success: ({ tempFilePath: small }) => {
    // 2) 上传到后端（后端落盘后由 CDN 提供访问）
    wx.uploadFile({
      url: BASE + '/api/upload',
      filePath: small,
      name: 'file',
      header: { Authorization: 'Bearer ' + token },
      formData: { familyId: 1 },
      success: (res) => {
        const body = JSON.parse(res.data);
        // 3) data.url 已是绝对地址（如 https://images.sean.ltd/2026/10/xxx.jpg），
        //    直接存入 images，提交 /transaction 时原样带上，渲染时不要再拼域名
        images.push(body.data.url);
      }
    });
  }
});
```

**错误码**:

| code | 说明                                 |
| ---- | ------------------------------------ |
| 400  | 文件为空 / 超过 5MB / 类型不支持 / 内容非图片 |
| 401  | 未登录                               |
| 403  | familyId 非本人所属家庭              |

### 38. 用户资料（昵称/头像）

**接口地址**: `/user/me`

**请求方式**: `GET` / `PATCH`

**请求头**: 需要 `Authorization`

**请求参数**（PATCH）:

| 参数名   | 类型   | 必填 | 说明                                                                 |
| -------- | ------ | ---- | -------------------------------------------------------------------- |
| nickname | String | 否   | 昵称；空串/空白忽略（不允许置空）                                     |
| avatar   | String | 否   | 头像地址；传空串 `""` 表示**清空头像**（会同步清空所有家庭内头像），不传/`null` 表示不修改 |

> 头像建议先 `POST /upload` 拿到绝对地址（如 `https://images.sean.ltd/2026/10/xxx.png`）再提交；
> 不要直接使用 `chooseAvatar` 的临时路径（`wxfile://` / `http://tmp/...`），重启后即失效。
> 清空示例：`{ "avatar": "" }`

**响应示例**（GET）:

```json
{
  "code": 0, "msg": "",
  "data": { "openid": "oABC...", "nickname": "小明", "avatar": "https://x/a.png", "privacyAgreed": true }
}
```

```json
{ "code": 0, "msg": "", "data": null }
```

**业务说明**:

- `user.nickname/avatar` 是全局身份：登录时若携带则刷新，`PATCH /user/me` 为「我的」页显式更新入口。
- 更新资料时**同步刷新该用户在所有家庭下的 `family_member.nickname/avatar`**，保证「我的」与成员列表一致。
- 家庭内单独改昵称仍可用 `PATCH /family/{familyId}/member/me`（只影响该家庭）。

## 附：权限与角色速查

- **家庭成员（member）**：可记账、改/删自己的记录、查看家庭/成员/分类/统计/预算、设置自己的提醒、退出家庭。
- **创建者（owner）**：在成员权限基础上，可创建/修改/删除家庭、生成/撤销邀请、审批成员、移除成员、转让身份、删除任意成员记录、设置预算、退出家庭（退出时若仍有其他成员则自动转让创建者身份，仅剩本人则整户解散）。
- **匿名（无 token）**：仅可登录、健康检测、查看邀请落地页（`GET /invitation/{token}`）、读取图片静态资源（`GET /files/**`）。申请加入（`POST /invitation/{token}/apply`）必须登录。
- 多家庭支持：用户可属于多个家庭；归属关系按「用户 + 具体 `familyId`」校验，`family_member` 唯一键 `(family_id, openid)`。
- `family_member` 只保留真实成员：退出/被移除即物理删除该行，同时把其在该家庭的流水置为作废（`transaction.status=0`）；重新申请经审批后按 upsert 重新加入。
