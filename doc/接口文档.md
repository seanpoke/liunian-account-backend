# 流年小账本 · 后端接口文档

> 家庭共享记账微信小程序后端（Spring Boot 3.3 + MyBatis-Plus）。
> 生成日期：2026-09-28。本文件覆盖全部 REST 接口，字段以代码实现为准。

## 通用约定

- **Base URL**：`http://<host>:<port>/api`（开发环境端口 `8445`，context-path `/api`）。
- **请求/响应格式**：均为 JSON，`Content-Type: application/json; charset=UTF-8`。
- **鉴权**：除下方标注「接口层不校验 token（匿名可调用）」的接口外，其余接口均需在请求头携带：

  | 请求头        | 类型   | 必填 | 说明                              |
  | ------------- | ------ | ---- | --------------------------------- |
  | Authorization | String | 是   | `Bearer ` + 登录返回的 `token`    |

  缺省或非法 token 返回 `{"code":401,"msg":"未登录/鉴权失败/登录已失效"}`。
- **统一响应结构**：`{ "code": int, "msg": string, "data": object|array|null }`。`code=0` 表示成功；非 0 为业务错误，错误信息在 `msg`。
- **金额单位**：所有 `amount` 字段均为整数「分」（如 `3500` 表示 ¥35.00）。
- **日期格式**：入参/出参日期为 `yyyy-MM-dd`；提醒时间为 `HH:mm`（24 小时）。
- **ID 类型**：`familyId` / `memberId` / `categoryId` / `id`（账目、邀请等）均为自增 `BIGINT`，以数字（JSON number）传递，字符串分类字面量（如 `g_exp_food`）已废弃。

### 错误码

| code | 含义                                   |
| ---- | -------------------------------------- |
| 400  | 参数错误 / 资源不存在（如分类、记录）  |
| 401  | 未登录 / token 无效或已失效            |
| 403  | 越权（非家庭成员 / 仅创建者可操作）    |
| 409  | 冲突（重复操作 / 人数上限）            |
| 410  | 已失效（邀请过期 / 已使用 / 已撤销）  |
| 500  | 服务器内部错误                         |

### 1. 用户登录（微信 code 换 token）

**接口地址**: `/login`

**请求方式**: `POST`

**是否鉴权**: 否（接口层不校验 token，匿名可调用）

**请求参数**:

| 参数名   | 类型   | 必填 | 说明                         |
| -------- | ------ | ---- | ---------------------------- |
| code     | String | 是   | 微信登录 code（wx.login 获取）|
| unionid  | String | 否   | 微信 unionid（授权后回传）   |
| nickname | String | 否   | 用户昵称（首次自动建用户）   |
| avatar   | String | 否   | 头像 URL                     |

**请求示例**:

```json
{
  "code": "081abc...",
  "nickname": "小明",
  "avatar": "https://x/a.png"
}
```

**响应示例**:

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "openid": "oABC123def",
    "isMember": true,
    "familyId": 1
  }
}
```

**响应字段说明**:

| 字段     | 类型           | 说明                                          |
| -------- | -------------- | --------------------------------------------- |
| token    | String         | JWT，有效期见服务端配置；需存入本地后续携带   |
| openid   | String         | 用户唯一标识                                  |
| isMember | Boolean        | 是否已加入某家庭（true 可直进账本）           |
| familyId | Long/空字符串  | 所属家庭 ID；未加入家庭时为 `""`              |

**业务说明**:

- 用 `code` 调微信 `code2Session` 换取 `openid`；首次登录自动创建 `user` 记录。
- 登录成功后在 Redis 写入 `auth:jti:<jti>` 实现会话（支持主动失效）；后续请求依赖该 token。
- `WX_MOCK=true` 时 `code` 可为任意字符串，跳过真实微信校验（仅开发环境）。

**错误码**:

| code | 说明                       |
| ---- | -------------------------- |
| 400  | 参数错误：code 不能为空    |
| 401  | 获取 openid 失败           |

### 4. 申请加入家庭

**接口地址**: `/invitation/{token}/apply`

**请求方式**: `POST`

**是否鉴权**: 否（接口层不校验 token；申请人以其自身登录后调用，body 仅传昵称头像）

**路径参数**:

| 参数名 | 类型   | 必填 | 说明     |
| ------ | ------ | ---- | -------- |
| token  | String | 是   | 邀请令牌 |

**请求参数**:

| 参数名  | 类型   | 必填 | 说明           |
| ------- | ------ | ---- | -------------- |
| nickname| String | 否   | 申请人昵称     |
| avatar  | String | 否   | 申请人头像 URL |

**请求示例**:

```json
{ "nickname": "小明", "avatar": "http://x/a.png" }
```

**响应示例**:

```json
{ "code": 0, "msg": "", "data": { "status": "pending" } }
```

**业务说明**:

- 邀请有效且申请人不在该家庭（active/pending）时，写入一条 `status=pending` 的家庭成员记录，并通知创建者。
- 曾被拒绝且在拉黑窗口（默认 24h）内的申请会被拦截。

**错误码**:

| code | 说明                       |
| ---- | -------------------------- |
| 410  | 邀请已失效                 |
| 409  | 申请被拒请稍后再试 / 你已在该家庭中 |

### 8. 生成邀请（创建者操作）

**接口地址**: `/invitation`

**请求方式**: `POST`

**请求头**: 需要 `Authorization`

**请求参数**:

| 参数名   | 类型   | 必填 | 说明                                          |
| -------- | ------ | ---- | --------------------------------------------- |
| familyId | Long   | 是   | 家庭 ID                                       |
| type     | String | 否   | `share`（默认，普通分享）或 `qr`（带小程序码）|

**请求示例**:

```json
{ "familyId": 1, "type": "qr" }
```

**响应示例**:

```json
{
  "code": 0, "msg": "",
  "data": {
    "token": "551a9fb48cd74203aa205eb81c103ef3",
    "expireAt": "2026-10-05T14:36:00",
    "qrImageUrl": "https://.../wxacode.png"
  }
}
```

**响应字段说明**:

| 字段       | 类型   | 说明                                  |
| ---------- | ------ | ------------------------------------- |
| token      | String | 邀请令牌（用于分享链接 / apply / 小程序码）|
| expireAt   | String | 过期时间（ISO，默认 168 小时后）      |
| qrImageUrl | String | `type=qr` 时返回小程序码 URL，否则为 `""` |

**业务说明**:

- 仅创建者可生成；家庭人数达上限（默认 10）返回 409。
- 邀请令牌为 UUID（无连字符），非数据库 ID。

**错误码**:

| code | 说明               |
| ---- | ------------------ |
| 403  | 仅创建者可操作     |
| 409  | 家庭人数已达上限   |

### 18. 分类列表

**接口地址**: `/categories`

**请求方式**: `GET`

**请求参数**:

| 参数名   | 类型   | 必填 | 说明                              |
| -------- | ------ | ---- | --------------------------------- |
| familyId | Long   | 是   | 家庭 ID（同时返回该家庭 + 系统预置分类）|
| type     | String | 否   | `income` / `expense` 过滤         |

**请求示例**: `/categories?familyId=1&type=expense`

**响应示例**:

```json
{
  "code": 0, "msg": "",
  "data": [
    { "id": 1, "familyId": null, "name": "餐饮", "type": "expense", "icon": "food", "color": "#FF7043", "sort": 1, "isSystem": 1 },
    { "id": 12, "familyId": 1, "name": "宝宝用品", "type": "expense", "icon": "", "color": "", "sort": 1, "isSystem": 0 }
  ]
}
```

**响应字段说明**:

| 字段     | 类型           | 说明                                  |
| -------- | -------------- | ------------------------------------- |
| id       | Long           | 分类 ID                               |
| familyId | Long / null    | 所属家庭；`null` 表示系统预置（全局）|
| name     | String         | 分类名                                |
| type     | String         | `income` / `expense`                 |
| icon     | String         | 图标标识                              |
| color    | String         | 颜色（HEX）                           |

- 返回「系统预置分类（`family_id IS NULL`）+ 本家庭自定义分类」的并集，按 `sort` 升序。

## 附：权限与角色速查

- **家庭成员（member）**：可记账、改/删自己的记录、查看家庭/成员/分类/统计/预算、设置自己的提醒、退出家庭。
- **创建者（owner）**：在成员权限基础上，可创建/修改/删除家庭、生成/撤销邀请、审批成员、移除成员、转让身份、删除任意成员记录、设置预算。
- **匿名（无 token）**：仅可登录、健康检测、查看/申请邀请（接口层不校验 token）。
- 单家庭约束在应用层校验；`family_member` 唯一键 `(family_id, openid)`，`removed` 行不物理删除，重新申请走 upsert。
